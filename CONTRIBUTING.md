# Contributing

Contributions are welcome. Please follow these guidelines:

- Open an issue first for non-trivial changes.
- Keep PRs focused on a single concern.
- All code must pass `python3 -m py_compile` and existing tests (`python3 -m pytest -q`).
- No secrets, credentials, or personal data in code or commits.
- Follow existing code style; add tests for new logic.
- By contributing you agree your changes are licensed under the MIT License.

For security issues, report privately via GitHub Security Advisories.
